# فكة — نسخة تجريبية للتصميم (v2)

نموذج تفاعلي لشاشات تصميم فكة، للتنقّل باللمس على الجوال. **ليس** التطبيق التشغيلي، ولا يتصل بواجهة فكة البرمجية.

- إنشاء حساب: ترحيب ← جوال (`5` + 8 أرقام) ← رمز 6 خانات (أي رمز أو `123456`) ← الملف ← +20 نقطة ← أسلوب الادخار ← المستويات ← ربط البنك ← +40 نقطة ← الرئيسية.
- تسجيل الدخول: بعد التحقق تنتقل مباشرة إلى الرئيسية ببيانات العرض (فهد العتيبي، 380 نقطة، مستوى حصّالة).
- النقاط للتحفيز فقط، بلا قيمة نقدية وبلا سحب على جوائز.

## تشغيل محلي

افتح `index.html` في المتصفح، أو:

```bash
python3 -m http.server 8080
```
