# فكة — نسخة تجريبية للتصميم (v2)

نموذج تفاعلي لشاشات تصميم فكة، للتنقّل باللمس على الجوال. **ليس** التطبيق التشغيلي، ولا يتصل بواجهة فكة البرمجية.

- إنشاء حساب: ترحيب ← جوال (`5` + 8 أرقام) ← رمز 6 خانات (أي رمز أو `123456`) ← الملف ← +20 نقطة ← أسلوب الادخار ← المستويات ← ربط البنك ← +40 نقطة ← الرئيسية.
- الدخول: من الترحيب «الدخول بنفاذ» أو «الدخول برقم الجوال». نفاذ محاكاة: أي هوية 10 أرقام تبدأ بـ 1 أو 2؛ الانتظار يُوافق بعد ~4 ثوانٍ مع أزرار لمعاينة الرفض/انتهاء الوقت/عدم التوفر. الرقم `1098765432` حساب قائم (فهد العتيبي، 380 نقطة، مستوى فضي) وينتقل للرئيسية بعد تأكيد الاسم.
- تسجيل الدخول برقم الجوال: بعد التحقق تنتقل مباشرة إلى الرئيسية ببيانات العرض إن اخترت الدخول، أو لتكملة الملف إن أنشأت حسابًا.
- النقاط للتحفيز فقط، بلا قيمة نقدية وبلا سحب على جوائز.

## تشغيل محلي

افتح `index.html` في المتصفح، أو:

```bash
python3 -m http.server 8080
```

على الآيفون: شارك → «إضافة إلى الشاشة الرئيسية» لفتحها بملء الشاشة بدون شريط المتصفح.
